# Basic Flask App

This project is a simple Flask application with a single route `/` that renders a basic HTML page.

## Requirements
- Python 3.7
- Flask
- Pycodestyle (version 2.5)

## Setup and Execution
1. Ensure you have Python 3.7 installed.
2. Install Flask using `pip install Flask`.
3. Run the application using `./0-app.py`.
4. Visit `http://127.0.0.1:5000` to see the rendered HTML page.

## Files
- `0-app.py`: Main Flask application.
- `templates/0-index.html`: HTML template for the main route.
